# SIGAPRO IA — leitura visual de Quadro I e II (QA)
A primeira fase da matriz aceita texto copiado ou transcrição manual. Este incremento permite usar uma captura nítida **recortada da tabela do PDF** (JPG/PNG; não envia o PDF inteiro). O administrador autoriza expressamente o envio para Cloudflare Workers AI, modelo fixo `@cf/meta/llama-3.2-11b-vision-instruct`, com a mesma autorização JWT municipal de `/api/ai-assistant`. A API permite resposta somente em homologação Vercel, com Neon QA isolado, e valida imagem, MIME, tamanho e perfil administrativo.

**Nenhum reconhecimento visual é considerado fonte oficial.** A IA só propõe a transcrição; o operador deve comparar número por número, editar o texto, marcar a conferência da transcrição, e posteriormente extrair e conferir candidatos. A ausência de certeza deve ficar como `[ILEGÍVEL]`, nunca convertida em número. Um modelo visual tem risco de trocar linhas/colunas, especialmente em tabelas densas; não alegar precisão de OCR.

**Ações manuais para habilitar em Vercel QA (sem expor segredos):** configurar `SIGAPRO_AI_PROVIDER=cloudflare`, `SIGAPRO_CF_ACCOUNT_ID`, `SIGAPRO_CF_API_TOKEN`, `SIGAPRO_CF_MODEL=@cf/zai-org/glm-4.7-flash` (texto) exclusivamente para Preview + gitBranch de PR #116. A visão usa modelo fixo separado e exige que a conta tenha aceitado previamente a licença Meta. Nunca copiar credenciais por chat ou habilitar a prévia sobre a base oficial.

Leitura usa no máximo 1,05 MB por imagem (cliente compacta JPEG) para respeitar o limite de requisição. Não armazena imagens no Neon/R2. Para obter um recorte, abrir quadro oficial em 100%-150% e capturar uma linha e cabeçalho (Win+Shift+S); escolher imagem salva. O navegador não consegue obter os pixels de um PDF nativo embutido sem biblioteca de renderização — esta etapa **não é OCR direto do PDF**. A automação de múltiplas páginas depende de um renderizador PDF local mais verificação de transcrição/linhas com testes próprios.
